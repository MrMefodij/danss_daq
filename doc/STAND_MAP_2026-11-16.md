# Стенд ДАНСС-2: платы, счётчики, рабочие напряжения (16.11.2026)

Источник напряжений и счётчиков — база тестирования `DANSS-II.db` от Игоря (таблицы `SiPM_boards`:
ID термометра платы 8SiPM, Vbreak1–8, Vset1–8; `Strips`: счётчик и ID плат на левом и правом
концах). ID — из `modbus_tool info` на стенде 16.11.2026. Повторить: `tools/sipm_db.py`.

- **Все 24 ID стенда есть в базе** — это заодно подтверждает порядок байтов ID (младший байт
  регистра — первый байт ROM).
- **STAND-01 (адрес 1) — левые концы счётчиков, STAND-02 (адрес 2) — правые.** Канал k левой =
  канал 11−k правой — правило Игоря подтверждено на 8 счётчиках из 9, которые есть в базе.
- Канал 1 левой (`28FFB05F…`, в базе счётчик 2505) и канал 10 правой (`28FFF81D…`, в базе
  счётчик 2510) — в базе это разные счётчики: на стенде платы переставлены или подключены не к
  тем счётчикам — **проверить на стенде**.
- 3 пары (ch0↔ch11, ch2↔ch9, ch10↔ch1) — платы 8SiPM есть в базе, счётчиков с ними нет.
- Рабочие напряжения Vset — 54.8…56.8 В (у каждого из 8 SiPM своё); Vset − Vbreak ≈ 3.5…4.9 В
  (в среднем 3.8 В). Тест плат 8SiPM — при 23–25 °C, на стенде сейчас 22–23 °C.
