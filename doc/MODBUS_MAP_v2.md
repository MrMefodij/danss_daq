# Карта регистров Modbus процессорной платы — версия 2 (октябрь 2026)

Источник: письмо Игоря, октябрь 2026 («почти окончательная функциональность»).
Заменяет прежнюю карту (ADC seq 0, trip 1, токи 2–13, температуры 14–25, CSR в holding 0, DAC 1–96).
Константы в коде: `include/common/constants.h`, раздел «Board Register Map — v2».

На одну процессорную плату приходится **3 аналоговые платы** и 12 каналов SiPM.
«По плате» в input 1, input 2 и holding 97 — бит на аналоговую плату.

## Input-регистры (FC 0x04)

| Адрес | Содержимое |
|---|---|
| 0 | Порядковый номер обновления; растёт в конце каждого цикла |
| 1 | Статус HV: `0ttt eeee eeee eeee` — `t` trip по аналоговой плате, `e` HV включено по каналу |
| 2 | `0000 0rrr 0000 0aaa` — `r` разрешение trip, `a` усиление (по аналоговой плате) |
| 3–14 | Токи утечки SiPM (12 каналов) |
| 15–26 | Температуры SiPM (12 каналов) |
| 27 | Температура CPU |
| 28–99 | Резерв |
| 100–147 | ID термометров 0–11 (по 4 регистра) |
| 148–149 | CPU ID |
| 150–245 | Обратное чтение DAC (96) |
| 246 | Смещение датчика температуры CPU |
| 247–249 | Резерв |
| 250–761 | Обратное чтение scratchpad (512 слов) |
| 1000 | Отладочное чтение |

## Holding-регистры (FC 0x03 / 0x06 / 0x10)

| Адрес | Содержимое |
|---|---|
| 0–95 | Уставки DAC |
| 96 | Counter ON/OFF (SiPM HV enable), бит на канал |
| 97 | Усиление и разрешение trip, бит на аналоговую плату |
| 98 | Global CSR. Команды: 0 нет операции, 101 загрузить из scratchpad, 103 стереть scratchpad (перед сохранением), 105 сохранить в scratchpad. Статус: 0 успех, 10 неизвестная команда, 20 ошибка |
| 99 | Глобальная задержка между циклами |
| 100 | Адрес устройства — задаётся только при заводском адресе 247: стереть scratchpad → перезагрузить → записать адрес → сохранить |
| 1000 | Отладочная запись |

## Scratchpad (энергонезависимая память)

| Слово | Содержимое |
|---|---|
| 0–95 | DAC |
| 96 | SiPM HV enable |
| 99 | Глобальная задержка |
| 100 | Адрес Modbus |
| 511 | Контрольная сумма: сумма всех слов = 0xAA55 |

## Опрос

- Каждый цикл: input 0–27 (28 регистров) и holding 0–100 (101 регистр) — по одной транзакции.
- Свежесть: если input 0 не изменился с прошлого опроса — плата зависла или цикл остановлен.
- Сверка DAC: holding 0–95 против input 150–245.
- Раз в сутки: ID термометров и CPU (input 100–149), scratchpad (input 250–761, 5 транзакций), контрольная сумма 0xAA55.

## Не подтверждено (вопросы к Игорю)

1. Резерв начинается с 28 (в письме «27–99»)?
2. Единицы токов и температур; как применять смещение из регистра 246.
3. Каналы по аналоговым платам: в коде предполагается 0–3, 4–7, 8–11 и бит 0 = плата 0 / канал 0.
4. Holding 96: «Counter ON/OFF» и «SiPM HV enable» — одно и то же?
5. Длительность команд 103/105; отвечает ли плата во время их выполнения.
6. Загружается ли scratchpad (101) автоматически при включении.
7. Контрольная сумма — по модулю 2^16? Раскладка битов holding 97 такая же, как в input 2?
8. Скорость 19200 и ограничения на частоту запросов.
