# Карта регистров Modbus процессорной платы — версия 2 (октябрь 2026)

Источник: письмо Игоря, октябрь 2026 («почти окончательная функциональность»).
Заменяет прежнюю карту (ADC seq 0, trip 1, токи 2–13, температуры 14–25, CSR в holding 0, DAC 1–96).
Константы в коде: `include/common/constants.h`, раздел «Board Register Map — v2».

На одну процессорную плату приходится **3 аналоговые платы** и 12 каналов SiPM.
«По плате» в input 1, input 2 и holding 97 — бит на аналоговую плату.

## Input-регистры (FC 0x04)

| Адрес | Содержимое |
|---|---|
| 0 | Порядковый номер обновления; растёт в конце каждого цикла |
| 1 | Статус HV: `0ttt eeee eeee eeee` — `t` trip по аналоговой плате, `e` HV включено по каналу |
| 2 | `0000 0rrr 0000 0aaa` — `r` разрешение trip, `a` усиление (по аналоговой плате) |
| 3–14 | Токи утечки SiPM (12 каналов) |
| 15–26 | Температуры SiPM (12 каналов) |
| 27 | Температура CPU |
| 28–99 | Резерв |
| 100–147 | ID термометров 0–11 (по 4 регистра) |
| 148–149 | CPU ID |
| 150–245 | Обратное чтение DAC (96) |
| 246 | Смещение датчика температуры CPU |
| 247–249 | Резерв |
| 250–761 | Обратное чтение scratchpad (512 слов) |
| 1000 | Отладочное чтение |

## Holding-регистры (FC 0x03 / 0x06 / 0x10)

| Адрес | Содержимое |
|---|---|
| 0–95 | Уставки DAC |
| 96 | Counter ON/OFF (SiPM HV enable), бит на канал |
| 97 | Усиление и разрешение trip, бит на аналоговую плату |
| 98 | Global CSR. Команды: 0 нет операции, 101 загрузить из scratchpad, 103 стереть scratchpad (перед сохранением), 105 сохранить в scratchpad. Статус: 0 успех, 10 неизвестная команда, 20 ошибка |
| 99 | Глобальная задержка между циклами |
| 100 | Адрес устройства — задаётся только при заводском адресе 247: стереть scratchpad → перезагрузить → записать адрес → сохранить |
| 1000 | Отладочная запись |

## Scratchpad (энергонезависимая память)

| Слово | Содержимое |
|---|---|
| 0–95 | DAC |
| 96 | SiPM HV enable |
| 99 | Глобальная задержка |
| 100 | Адрес Modbus |
| 511 | Контрольная сумма: сумма всех слов = 0xAA55 |

## Опрос (danss_sc_fe)

- Каждый цикл: input 0–27, holding 0–100, input 150–245 (обратное чтение DAC), input 100–149 +
  246 (ID термометров, CPU ID) — частота запросов не ограничена (Игорь, 09.11.2026).
- Свежесть: если input 0 не меняется ≥ 1 с + 3 × cycle delay — цикл платы стоит.
- Сверка DAC: holding 0–95 против input 150–245 — только для видимых аналоговых плат.
- Раз в сутки (план): scratchpad (input 250–761, 5 транзакций), контрольная сумма 0xAA55.

## Что известно о прошивке

**Подтверждено (07.11.2026):**
- Скорость **38400 8N1** на всех платах, включая стенд (1, 2, 3); в сентябре было 19200.
- Holding 96: «Counter ON/OFF» = SiPM HV enable (включение HV по каналам).
- Новый адрес (holding 100) действует сразу после сохранения, без перезагрузки.
- Резерв input-регистров — 28–99.
- Scratchpad загружается в рабочие регистры сам при включении питания — команда 101 после
  сбоя питания не нужна; перезагрузку платы видно по сбросу счётчика input 0.
- Контрольная сумма — сумма 512 слов по модулю 2^16 = 0xAA55 (сходится на плате 17).

**Проверено на плате 17 (к плате ничего не подключено):**
- Вся карта v2 читается без исключений Modbus; ответ на 28 регистров ≈ 25 мс.
- Цикл платы ≈ 134 мс при задержке (holding 99) = 0; счётчик input 0 растёт без пропусков
  (16 бит — переполняется примерно раз в 2.4 ч: сравнивать на «изменился», не на «вырос»).
- CSR: стирание (103) + сохранение (105) работают, статус 0; статус читается после следующего
  цикла платы. Восстановление из резервной копии (`modbus_tool restore`) работает.
- Без аналоговых плат и термометров: температуры SiPM = 32769 (0x8001), ID термометров = 0,
  токи 345–361 (raw), **обратное чтение DAC = 0** при любой уставке (1, 100, 1000), хотя
  уставка в holding записывается и сохраняется.
- CPU 180 (raw), смещение (246) = 40960 (0xA000).

## Ответы Игоря (письмо, 09.11.2026)

1. **Подключено ли что-то.**
   - DAC стоят на аналоговых платах, по 32 канала на плату; без платы обратное чтение = 0.
   - Температура SiPM 0x8001 — **ошибка доступа к счётчику** (микросхема термометра стоит на
     счётчике, на плате 8SiPM).
   - ID термометров — фактически ID плат 8SiPM на счётчиках; **ID = 0 — признак отсутствия
     счётчика** (этой его стороны).
   - Явного признака «аналоговая плата подключена» нет (можно добавить в прошивку). Варианты:
     все 32 обратных чтения DAC этой платы = 0 (в реальной работе маловероятно) или выставить
     бит запрета trip и прочитать его обратно.
   - **В рабочем режиме должны быть ВСЕ каналы.** Отсутствие — аларм; отключать канал или
     плату только вручную, когда оператор подтвердил, что понимает, что это сломано, и
     согласен работать без этого.
2. **Единицы.**
   - Ток утечки: 10-битный АЦП, максимум = 6.6 мкА → **I [мкА] = ADC × 6.6 / 1024**.
   - Температура SiPM: **1/16 °C**, знаковая (int16; отрицательные возможны).
   - Температура CPU (input 27) и смещение (246): пересчёт не получается и по datasheet/TRM;
     не нужна — оставляем raw.
3. **Каналы и биты.**
   - Каналы 0–11 — по аналоговым (материнским) платам по 4 подряд; нумерация на плате идёт
     подряд от центра (от процессорной платы).
   - Концы одного счётчика подключены к разным платам: «левой» и «правой» (если смотреть на
     детектор). Счётчик на канале 0 правой платы — на канале 11 левой и т.д. Итоговая
     нумерация счётчиков — за нами; желательно, чтобы X, Y, Z давали правую тройку.
   - Бит 0 полей trip/разрешения/усиления (input 1, 2, holding 97) — аналоговая плата 0;
     бит 0 разрешения HV — канал 0. Раскладка holding 97 = input 2. **Подтверждено.**
4. **103/105.** 103 — до 36 мс (процессор останавливается, watchdog на это время выключен),
   105 — до 15 мс. **Ответ Modbus посылается после завершения команды**; таймаута не бывает.
   Что будет, если в это время на шине идёт обмен с другим адресом, — не проверялось.
5. **Частота запросов** — ограничений нет.
6. Автозагрузка scratchpad при включении работает **только если сошлась контрольная сумма**.

**Следствия для кода:**
- Токи → мкА, температуры SiPM → °C (int16 / 16; 0x8001 — нет данных) в банках и ODB.
- Ожидаемый состав (какие аналоговые платы и счётчики должны быть) задаётся явно; по
  умолчанию — всё. Отсутствие ожидаемого — аларм. Исключение — только вручную (оператор), с
  записью в журнал.
- Признаки: аналоговая плата — не все 32 обратных чтения DAC = 0; счётчик (сторона) — ID
  термометра ≠ 0, температура ≠ 0x8001. Признак «аналоговая плата» по температуре — неверен.
- Во время 103/105 на ветке не слать запросы другим платам (запись идёт из потока опроса
  ветки — это и так выполняется).
- Таблица соответствия «канал платы → счётчик (X/Y/Z, сторона)» — отдельная задача.
